# MagnetCursor

Магнитный курсор для Windows: курсор жёстко прилипает ко всему кликабельному —
кнопкам (включая свернуть/развернуть/закрыть), ссылкам, пунктам меню, ярлыкам,
картинкам-ссылкам. Увёл мышь прочь или дёрнул резко — отпускает.

## Запуск

```
pip install -r requirements.txt
python -m magnetcursor
```

Откроется окно **MagnetCursor** (сворачивается, поверх остальных):
- статус ON/OFF, счётчик видимых целей;
- кнопки Включить/Выключить и Выход.

Горячие клавиши: `F9` — вкл/выкл, `F12` — выход.

## Как это работает

1. `targets.py` — собирает интерактивные элементы активного окна + видимые
   ярлыки рабочего стола через Windows UI Automation (кэш в фоне).
   Строгий режим (`MAGNET_STRICT`, по умолчанию вкл): только кнопки, ссылки,
   меню, табы, чекбоксы (`MAGNET_STRICT = False` в config.py — вернуть всё кликабельное).
   Берёт всё с паттернами Invoke/Toggle/ExpandCollapse/SelectionItem и
   MSAA-ссылки. Цели, перекрытые другими окнами, отбрасываются проверкой
   z-порядка; при смене фокуса кэш сбрасывается мгновенно.
2. `snap.py` — жёсткий снап в центр цели с гистерезисом
   (войти — `MAGNET_CAPTURE`, выйти — `MAGNET_RELEASE`), детект вырывания
   (рывок / тяга прочь) с паузой перед повторным захватом.
3. `overlay.py` — зелёная рамка вокруг цели поверх всех окон (click-through).
4. `handcheck.py` (`python -m magnetcursor.handcheck`) — детектор промахов:
   следит за формой курсора-руки и записывает места, где магнит не видит цель.

## Настройки (`magnetcursor/config.py`)

`MAGNET_CAPTURE` / `MAGNET_RELEASE` — радиусы захвата/выхода в px,
`MAGNET_FLICK_PX` — рывок для мгновенного отпускания,
`MAGNET_COOLDOWN` — пауза перед повторным захватом.

## Браузеры

Chrome/Edge показывают ссылки страниц, только если запущены с флагом
`--force-renderer-accessibility` (дописать в ярлык после `.exe`).
Firefox работает сразу.
